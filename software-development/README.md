## 与其他目录的边界

### Software Development vs System Design

System Design 决定：

> **应该采用什么技术方案。**

Software Development 进一步解决：

> **怎样正确地把这个方案实现出来。**

例如：

```text
System Design：
业务写操作需要支持审计。

Software Development：
写接口时如何同时提交业务数据和审计记录，
失败时如何保证事务回滚。
```

### Software Development vs Feature Design

Feature Design 定义业务行为。

例如：

```text
重复导入的数据应该跳过。
```

Software Development 则负责解决：

```text
如何判断重复数据？
唯一键如何定义？
批量导入怎样保证幂等？
前后端分别进行哪些校验？
```
